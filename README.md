# Hard Skills Lab

Bilingual (French/English) website for Hard Skills Lab — training young Africans in data and AI through free, online, practical, project-first learning.

## Tech Stack

- **Astro** (static-first)
- **Tailwind CSS v4** (via Vite plugin)
- **TypeScript** (strict)

## Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Install

```bash
npm install
```
